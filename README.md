# MorphSnos — 2D-анимация мессенджера (2:3)

Короткий ролик на 59,6 с по сценарию из 5 сцен: покупка NFT-подарка «Scared Cat» →
угроза доксом с таймером → переписка и подарки-медведи → чат с ботом **MorphSnos** →
собеседник исчезает, вместо аватарки — приведение, вместо ника «Удалённый аккаунт».

## Сцены и тайминг
| с | сцена | что происходит |
|---|---|---|
| 0,0–12,5 | **1. Витрина подарков** | сетка коллекции «Scared Cat», коты покачиваются, скролл пальцем, подсветка карточки, тап → карточка подарка → «Купить» → модалка «Вы подтверждаете оплату?» → «Да» → подарок летит по дуге в аватар профиля с искрами, субтитр «Подарок добавлен в профиль» |
| 12,5–24,2 | **2. Таймер и входящее** | список чатов, круглый таймер 3:00 → 0:00, баннер уведомления от `doxsv#tbog`, угроза, «ты кто?», ответ «…давай быстрее максимка», крупный субтитр «Но это было не моё имя...», дрожание экрана и красное свечение |
| 24,2–32,6 | **3. Переписка** | «хорошо, хорошо. Щас отправлю подарок» → «жду» → «черт, у меня нету звёзд на передачу» → два подарка-медведя по 13 ★ с мягким свечением |
| 32,6–43,0 | **4. Бот MorphSnos** | ввод `@doxsv_tbog`, «выполняю...» с полосой загрузки ровно 3 с → «готово» |
| 43,0–59,6 | **5. Возврат и исчезновение** | аватарка растворяется в приведение, ник → «Удалённый аккаунт», статус → «был(а) давно», кнопка «Удалить чат», свечение по краям и финальные субтитры |

## Результат (`out/`)
| файл | разрешение | что это |
|---|---|---|
| `morphsnos_1200x1800_60fps.mp4` | 1200×1800 (2:3), 60 fps, со звуком | основной файл |
| `morphsnos_800x1200_60fps.mp4` | 800×1200, со звуком | лёгкая версия |
| `preview_400x600.gif` | 400×600, 16 fps, без звука | короткое превью (оплата и полёт подарка, 4,4 с) |
| `soundtrack.wav` | 48 кГц, стерео | дорожка целиком |

## Как устроено
* `src/scene.html` — сцена на HTML/CSS/SVG. Вся анимация — чистая функция `window.__render(t)`,
  где `t` — время в секундах: никаких CSS-переходов, поэтому кадры воспроизводимы покадрово.
  Тайминг задаётся объектом `T` в начале скрипта, витрина и переписки — массивами
  `CATS`, `DOX`, `BOTMSG`; коты, медведи, приведение и звёзды рисуются SVG-функциями
  (`catSVG`, `bearSVG`, `ghostSVG`, `patSVG`), клавиатуры собираются из раскладок `RU` / `LAT`.
* `src/render.js` — покадровый захват через Playwright (Chromium). Кадры идут прямо в
  ffmpeg через конвейер, на диск не пишутся.
* `src/audio.py` — синтез всей дорожки с нуля (numpy, без сэмплов): клики интерфейса, свуши
  переходов, клавиатура, тёмное уведомление, тиканье таймера, «дзынь» подарка, гул обработки,
  аккорд «готово», исчезновение аккаунта и четыре музыкальные подложки. Тайминг берётся из
  того же словаря `T`, что и анимация.

## Перерендер
```bash
python3 src/audio.py
node src/render.js --fps 60 --scale 3 --audio out/soundtrack.wav \
     --out out/morphsnos_1200x1800_60fps.mp4
```
Отдельные кадры для проверки:
```bash
node src/render.js --preview "4.4,8.5,21.0,46.5" --frames /tmp/prev --scale 2
```
Полезные ключи: `--from/--to` (кусок таймлайна), `--frames` (PNG вместо видео), `--crf`.
